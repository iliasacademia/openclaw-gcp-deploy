Step 1 of 1

Connect Telegram

OpenClaw uses a Telegram bot to receive your messages and reply with AI-powered responses. You'll create a private bot in under a minute.

How to get your bot token

  1. Open Telegram and search for @BotFather (blue tick ✓)
  2. Tap Start, then send the command /newbot
  3. Choose a display name — e.g. My Claw Agent
  4. Choose a username ending in bot — e.g. myclawagent_bot
  5. BotFather replies with your token — copy it (looks like 123456789:ABCdef…)

Your bot is connected, but OpenClaw only replies to senders that you've explicitly paired. Open Telegram and send /start to your bot — keep this page open. Your pairing request will appear below within a few seconds. Then click Approve here.

What's next

  • Message your bot on Telegram
    The first message from a new sender triggers a pairing code — approve it in the dashboard under Access.
  • Connect Google (Gmail, Drive, Calendar)
    The gog CLI is pre-installed and the skill is enabled. To finish the OAuth handshake (one-time, ~2 min):
    1. Open OAuth consent screen → choose External → fill the required fields → add yourself as a Test user.
    2. Open Credentials → Create credentials → OAuth client ID → Desktop app → download the JSON.
    3. In the OpenClaw dashboard → Skills → gog → follow the authorise prompts with that JSON.
  • Explore skills
    Summarise, search, manage files and more — all from the dashboard's Skills tab.
